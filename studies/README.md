# Current KRI Space Autonomy research index

This index distinguishes the completed first experimental programme, the subsequent
property-alignment studies, and the information-aware enhancement phase of the same
KRI research programme. Historical sources and results remain unchanged.

## Evidence phases

| Phase | Current evidence and entry point | Scope |
| --- | --- | --- |
| Original E001-E005 programme | [Maintained evidence guide](../docs/post-release-maintenance.md) and [E005 correction](../docs/e005-corrigendum-2026-09-09.md) | Frozen historical records; original endpoint and custody limitations remain. |
| Property alignment | [Common-command construction](property-alignment-v1/candidate/README.md), [protective comparisons](property-alignment-v1/protective/README.md), [controlled predicate study](property-alignment-v1/causal/README.md) | Completed analytical and bounded simulated studies, not flight validation. |
| Further property-alignment checks | [Frozen evaluation](property-alignment-v1/campaign_v2/README.md), [independent certificate audit](property-alignment-v1/independent_hcw_campaign_v1/README.md), [robustness](property-alignment-v1/boundary_robustness_v1/README.md), [post-review checks](property-alignment-v1/post_review_correction_v1/README.md) | Preserve all supplied-input, finite-horizon and model-conditional boundaries. |

The property-alignment directory's original scaffold README describes its baseline
stage. Use the detailed component documents above for later completed work. Its
historical text and recorded source identities are deliberately retained.

The new phase has separate interfaces, geometry, budgets and engineering inputs.
It does not reopen E001-E005, replace the property-alignment outcomes, establish
KRI-STD-001 conformance or change an existing manuscript. New research and retained
historical evidence must be cited with their respective exact version identities.
