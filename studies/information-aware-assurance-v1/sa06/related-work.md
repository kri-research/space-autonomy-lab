# Sources and reuse boundaries

Checked 27 September 2026. This stage makes existing research usable through an
installed interface; it does not introduce a new control theorem or claim an
active-sensing advance.

The complete SA05 findings and SA01-SA04 evidence were read before selecting the
observation/finite-command assessment component. The decision-aware candidate is
not promoted as a superior operational controller. Its zero-acquisition and higher
modeled-cost outcomes remain in their original source-bound records.

Primary sources used for packaging are the Python Packaging Authority tutorial
at https://packaging.python.org/en/latest/tutorials/packaging-projects/ and the
setuptools configuration documentation at
https://setuptools.pypa.io/en/latest/userguide/pyproject_config.html . The selected
setuptools 84.0.0 and build 1.6.1 versions were checked using official PyPI metadata.
A separate hash-locked build environment leaves the old scientific locks intact.
No package-index upload is performed. The installed component uses no third-party
runtime dependency; the build tools are not bundled into it.

The primary robust output-feedback reference remains Brunke, Zhou and Schoellig,
*Robust Predictive Output-Feedback Safety Filter for Uncertain Nonlinear Control
Systems*, https://arxiv.org/abs/2212.08900. Its observer and terminal assumptions
support continuing-control claims that this finite assessment does not inherit.
The abstract/version page was rechecked for this integration stage; earlier
paper-specific inspections and their limits remain in the research records.

The current s-FEAST licence was read again from
https://github.com/treyra/s-FEAST/blob/master/LICENSE , blob
`c5302702b0f9f627636c536997fcf6f6ee1bcfd8`. Further use is restricted without written
permission. No permission was obtained and no s-FEAST code/data is included.
The package contains only explicitly inventoried KRI code under the repository's
Apache-2.0 licence. Import-relocated modules carry an adaptation notice, and the
full licence is included in distributions. The underlying numerical source is
unchanged. The existing Basilisk/SciPy comparison remains in its separately
licensed, pinned environment and is not copied into this small runtime package.

The current KRI publication page and formal v2.0 PDF were obtained using HTTPS on
the authorized host. The web-reader request failed; that did not substitute an
older edition. The full downloaded PDF and its digest were checked for the one
separate IMPLEMENTATION_NOTE.md; no standard or checklist content was changed.

The new SA06 workflow uses reviewed immutable v6 action commits with Node 24.
Existing workflow versions and their source bindings remain unchanged.
